## 🎯 Предустановленные профили каталога (Presets)

В окне каталога модулей (<kbd>F8</kbd>) доступны готовые пресеты:

- **Minimal Core (8)**: `['A1', 'B1', 'D1', 'D2', 'E1', 'F1', 'H1', 'H2']` — сбалансированный набор разработчика.
- **NOC Monitor (10)**: `['D1', 'D2', 'D3', 'D4', 'D5', 'G2', 'G3', 'E1', 'F1', 'H1']` — наблюдаемость и здоровье нод.

- **Enable All (70)**: Активация всех 70 модулей.
- **Clear All (0)**: Очистка рабочего пространства для сборки индивидуального лейаута с нуля.
